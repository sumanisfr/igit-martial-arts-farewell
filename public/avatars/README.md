Drop avatar images here so the app can display them in senior cards.

- Preferred format: PNG (square or near-square). Files should be named exactly as the card expects (lowercase):
  - `shilpi.png` → will show on Shilpi's card
  - `sujata.png` → will show on Sujata's card

- File path after adding: `public/avatars/sujata.png`

Notes:

- After placing the image, reload the dev server page at <http://localhost:5173/> (hard refresh may be needed).
- You can also click "Add Photo" on a card and paste a public image URL (PNG preferred) instead of using this folder.
- Do NOT commit private images to public repos unless you have permission.
