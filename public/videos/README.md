# Video Storage

## Instructions

Place your **Seniors.mp4** video file in this directory.

### File Name

The video should be named exactly: `Seniors.mp4`

### Supported Formats

- `.mp4` (H.264 codec recommended)
- `.webm`
- `.mov`

### Upload Steps

1. Export/render your farewell video as MP4
2. Name it `Seniors.mp4`
3. Copy it to this folder: `public/videos/Seniors.mp4`
4. The website will automatically serve it

### Fallback

If the local video is not found, the site will use the **Google Drive folder** as a fallback:

- Folder: <https://drive.google.com/drive/folders/175-pA7_x_mWq6C8cUgLFUql0hx-tMAKb>

### Video Specifications (Recommended)

- **Resolution:** 1920×1080 (Full HD)
- **Duration:** 2-5 minutes
- **Codec:** H.264 (MP4)
- **Bitrate:** 5-10 Mbps
- **Frame Rate:** 30 fps
